# 🌱 Plant Recognition (Streamlit App)

A **Streamlit-based web application** that recognizes plant species from leaf images using a trained deep learning model (`leaf_model.pth`).  

---

## ⚡ Getting Started

Follow these steps to set up and run the project on your local machine.

### Clone the repository

- git clone https://github.com/learnersurajsingh/plant-recognition.git

### Install dependencies

- pip install -r requirements.txt

### Run the Streamlit app

- streamlit run app.py
